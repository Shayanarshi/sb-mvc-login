Spring Boot MVC Login Application
A simple Spring Boot + Spring MVC + JSP + Spring Data JPA + MySQL login application.
This project demonstrates a basic username/password authentication flow using a layered architecture:
JSP → Controller → Service → Repository → MySQL Database
Features
- User login using username and password
- Authentication against a MySQL database
- Success page after valid login
- Error message for invalid username/password
- Displays the logged-in username
- Displays the login date and time
- Spring Data JPA repository for database access
- JSP views using Spring MVC view resolver

Database Setup
Create a MySQL database named sbms:
CREATE DATABASE sbms;
The application uses the following database configuration:
spring.datasource.url=jdbc:mysql://localhost:3306/sbms
spring.datasource.username=root
spring.datasource.password=YOUR_MYSQL_PASSWORD
Replace YOUR_MYSQL_PASSWORD with your local MySQL password.
The application uses:
spring.jpa.hibernate.ddl-auto=update
so Hibernate can create/update the required table structure automatically.
Add a test user
After the application creates the table, you can add a user manually if needed:
INSERT INTO login (username, password)
VALUES ('shayan', '1234');
The exact table name can depend on JPA/Hibernate naming configuration. If necessary, check the table generated by Hibernate or use the application's SQL output.

How to Run
1. Clone the project
git clone <your-repository-url>
cd sb-mvc-login
2. Configure MySQL
Make sure MySQL is running and update application.properties with your database username and password.
3. Build the project
Using Maven Wrapper on Windows:
mvnw.cmd clean install
Or, if Maven is installed:
mvn clean install
4. Run the application
mvnw.cmd spring-boot:run
Or run SbMvcLoginApplication.java directly from your IDE.
5. Open the login page
Open:
http://localhost:8080/login

Authentication Logic
The service checks whether the username exists first. This prevents a NullPointerException when an unknown username is entered.
Login login = repository.findById(username).orElse(null);

if (login != null) {
    if (login.getPassword().equals(password))
        return true;
    else
        return false;
}

return false;
Therefore:
Username	Password	Result
Correct	Correct	Success page
Correct	Wrong	Login page with error
Wrong	Wrong	Login page with error
Wrong	Correct	Login page with error


Important Classes
LoginController
Handles HTTP requests and controls navigation between the login and success pages.
- GET /login → displays the login page
- POST /check → validates the submitted credentials
LoginService
Contains the authentication/business logic.
LoginRepository
Uses Spring Data JPA to retrieve the login record from MySQL.
Login
JPA entity representing the login data. The username is used as the primary key.
Login.jsp
Contains the login form and displays the authentication error message.
Success.jsp
Displays the logged-in username and the current date/time.
API / URL Summary

Security Note
This is a learning/demo project. Passwords are currently stored and compared as plain text.
For a production application, use:
- Spring Security
- Password hashing such as BCrypt
- HTTPS
- Environment variables or secrets management for database credentials
- Proper session management
- CSRF protection
- Input validation
Do not commit real database passwords to GitHub. Use a placeholder such as YOUR_MYSQL_PASSWORD in application.properties and keep real credentials outside source control.
